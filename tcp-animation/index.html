How TCP moves bytes: segments, ports and sequence numbers

A browser on one machine talks to a web server on another. Watch each segment cross the wire, read its header, and see how ports pick the program and sequence numbers keep the bytes in order.

Port numberWhich program on the host. 16 bits, so 0–65535. Servers listen on well-known ports (80, 443, 22); clients get a temporary one from 49152–65535.
SegmentOne TCP unit: a 20-byte header plus a chunk of the byte stream, no bigger than the maximum segment size (MSS). Here MSS is 400 bytes.
Sequence & ack numbersseq is the stream position of the first payload byte. ack is the next byte the receiver expects, which acknowledges everything before it.
