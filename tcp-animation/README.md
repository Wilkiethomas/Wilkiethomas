# TCP Segments and Ports

An animated, self-contained illustration of how TCP works: port numbers,
segments, sequence and acknowledgment numbers, the three-way handshake,
segmentation of a large response, a dropped segment with retransmission,
and the connection close.

Open `index.html` in any browser. No build step and no dependencies
(the only external resource is a Google Fonts stylesheet, with system
fallbacks if it is unavailable).

Controls: Play / Pause, Back, Next, Restart, speed (0.5x, 1x, 2x), phase
chips to jump to a section. Arrow keys step, Space plays or pauses.
Respects `prefers-reduced-motion`.
